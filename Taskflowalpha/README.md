# TaskFlow — Gerenciador de Tarefas

Projeto de portfólio para Engenharia de Software: uma aplicação web simples para criar, concluir, filtrar e excluir tarefas.

## Tecnologias
- HTML5
- CSS3
- JavaScript (ES6+)
- LocalStorage
- Git/GitHub

## Como executar
1. Extraia o projeto.
2. Abra a pasta no VS Code.
3. Abra `index.html` no navegador ou use a extensão Live Server.
4. As tarefas ficam salvas no navegador usando LocalStorage.

## Funcionalidades
- Criar tarefas
- Marcar como concluída
- Excluir tarefas
- Filtrar por todas, pendentes e concluídas
- Contador de tarefas
- Persistência local
- Layout responsivo

## O que demonstra no currículo
- Manipulação do DOM
- Eventos e estado da aplicação
- CRUD no front-end
- Persistência com LocalStorage
- Organização de projeto
- Responsividade e acessibilidade básica
